## Résumé de l'analyse

### Demande 1 — Recalculs frontend
**Cause racine** : `staleTime` non défini dans `QueryClient` global → défaut 0ms. Chaque query est immédiatement stale après son premier fetch. Comme `refetchOnMount: true` (défaut), toute navigation déclenche un refetch.

**Solution** : Configurer `staleTime: 30_000` et `gcTime: 1_800_000` dans `providers.tsx`.

**Fait rassurant** : Tous les hooks individuels ont déjà un `staleTime` explicite (1-10min), donc le défaut global ne fait que couvrir les éventuels oublis.

### Demande 2 — Log spam backend
**Cause racine** : Double problème :
1. `request_logging_middleware` dans `main.py` loggue TOUTES les requêtes en INFO
2. `progress/page.tsx` a un `useEffect` avec `setInterval` à 2s pour `/progress/index/status` qui démarre même si l'indexation n'est pas en cours (fallback de 20s systématique)

**Solution** : 
1. Backend : logger les chemins de polling en DEBUG
2. Frontend : remplacer le `setInterval` manuel par `refetchInterval` React Query conditionnel

### Demande 3 — Monolithes backend
**Constat** : Le refactor v1.1.95 a bien réduit `real_run_analysis.py` (1528→14 lignes) mais d'autres fichiers restent problématiques :
- `routes/progress.py` : 677 lignes, 16× duplication du pattern `db_session_factory`
- `core/metrics.py` : 788 lignes, fonction god de 415 lignes
- `progress/indexer.py` : 734 lignes, fonction god de 379 lignes

**Solution** : Extraction ciblée (helper db_session_factory + sous-fonctions privées), pas de split en nouveaux modules.

### Demande 4 — Version centralisée
**Constat** : `"1.2.0"` est hardcodé dans 4 fichiers (main.py ×2, package.json, CHANGELOG.md). Aucun `VERSION` file, `pyproject.toml`, ou `__version__`.

**Solution** : Créer `VERSION` à la racine, le faire lire par `main.py`, ajouter script npm `sync-version`.

## Décisions de cadrage

1. **Priorité** : Lot 4 (version) → Lot 2 (log spam) → Lot 1 (cache) → Lot 3 (monolithes)
2. **staleTime global** : 30s (compromis performance/fraîcheur)
3. **Fichier VERSION** : racine du repo (convention standard)

5. **CHANGELOG** : reste manuel (pas d'automatisation)
