## Erreurs rencontrées

1. **Type error dans ReliefCard.tsx**: Le `formatter` du `Tooltip` Recharts attend `value: number | undefined` pas `value: number`. Corrigé en ajoutant une vérification `typeof value === 'number'` avant `Math.round()`.

## Décisions techniques

- **Fusion des séries par Map lookup** : Au lieu de fusionner par index, utilise un `Map<distanceKey, grade>` avec arrondi au mètre et recherche ±20m. Plus robuste si les séries ont des points d'échantillonnage différents.
- **`isValidNumber` utilisé directement** : La type predicate de TypeScript fonctionne correctement dans les ternaires JSX, pas besoin de cast explicite.
- **Annotations basées sur les séries réelles** : Les points de pente max/min sont trouvés dans les données fusionnées (séries elevation+grade), pas depuis les métriques summary. Cela garantit que les annotations correspondent à des points réels du graphique.
- **Pas de modification backend** : Conforme à la spec — toutes les données étaient déjà disponibles.

- **Faible** : La sub-nav utilise `bg-slate-50/90` pour le fond de la barre sticky. Si le fond de page change, l'effet de transparence peut révéler le contenu derrière. Actuellement cohérent avec le fond AppShell.
